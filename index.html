☁ Conectar Cloudinary

Cloudinary es el servicio de almacenamiento de fotos y videos que usará la app. El plan gratuito incluye 25 GB sin tarjeta de crédito. Seguí estos pasos una sola vez.

1
Crear cuenta gratuita
Entrá a cloudinary.com/users/register_free y creá tu cuenta con email. No necesitás tarjeta de crédito.
💡 El plan gratuito incluye 25 GB de almacenamiento y 25 créditos mensuales — más que suficiente para varios eventos.
2
Obtener tu Cloud Name
Una vez dentro, en el Dashboard (página principal) vas a ver tu Cloud Name — es algo como dxyz123abc. Copialo.
Cloud Name: dxyz123abc ← copiá este valor
3
Crear un Upload Preset
Esto permite que la app suba archivos sin exponer tu contraseña secreta. En Cloudinary:
1. Andá a Settings (engranaje ⚙ arriba a la derecha)
2. Clic en la pestaña "Upload"
3. Bajá hasta "Upload presets" y clic en "Add upload preset"
4. En "Preset name" escribí: momentos_eventos
5. En "Signing Mode" elegí "Unsigned"
6. Clic en "Save"
⚠ El modo "Unsigned" es necesario para que la app pueda subir sin un servidor. Es seguro para este uso.
4
Pegar los datos en la app ← EL PASO QUE BUSCABAS
Abrí el archivo momentos-app-v3.html con el Bloc de notas o cualquier editor de texto. Buscá estas dos líneas cerca del principio del código JavaScript y reemplazá los valores:
// ─── CLOUDINARY CONFIG ── COMPLETÁ ESTOS DATOS ─ const CLOUDINARY_CLOUD_NAME = 'TU_CLOUD_NAME'; ← reemplazá con tu Cloud Name const CLOUDINARY_UPLOAD_PRESET = 'TU_UPLOAD_PRESET'; ← reemplazá con momentos_eventos
Ejemplo con datos reales:
const CLOUDINARY_CLOUD_NAME = 'dxyz123abc'; const CLOUDINARY_UPLOAD_PRESET = 'momentos_eventos';
✅ Guardá el archivo y listo. Las fotos y videos se subirán directo a Cloudinary y quedarán guardados permanentemente.
5
Eliminar archivos de un evento
Cuando quieras borrar todos los archivos de un evento de Cloudinary:
1. Entrá a cloudinary.com → Media Library
2. Abrí la carpeta momentos → subcarpeta con el ID del evento
3. Seleccioná todos los archivos → Delete
💡 El botón "Eliminar evento" en la app borra el evento de tu lista. Para liberar espacio en Cloudinary, hacé este paso adicional.
